# Other MCP clients

Any client that supports hosted remote MCP over HTTP with OAuth 2.1 can connect.
Use `https://elevenflo.com/mcp` in the client's remote-server setup, `elevenflo`
as the server label, and pick OAuth when prompted.

Clients limited to local stdio servers or to a manually pasted bearer token
cannot connect. Email support@elevenflo.com to discuss options.
