# Verify the connection

In a client with an MCP prompt picker, select **Brief a Chapter 11 case** (`case_brief`). Enter a debtor name or case number and the question you need answered. Leave the question blank for a docket brief. Leaving both fields blank opens the FTX Trading Ltd. example. Review the question and send it in the same conversation.

You can also copy this question into a connected assistant:

```text
Use ElevenFlo to find FTX Trading Ltd. Review the five latest docket entries. Which one, if any, changes what a creditor needs to know? Give the filing date and docket number. Link the PDF page that supports the finding. Distinguish a request from a court order.
```

Check that the answer identifies the debtor you selected. For the FTX example, the case is FTX Trading Ltd. (case ID 1857). Open the cited page to check the finding. Continue the research in the same conversation. If the assistant cannot find the case, see Troubleshooting.
