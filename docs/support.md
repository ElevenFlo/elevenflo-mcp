# Support

Email support@elevenflo.com. Copy this block, fill it in, and include it:

```text
Organization:
Account email:
MCP client and version:
Endpoint URL:
Case or filing involved:
Tool or prompt attempted:
Approximate time:
Error message:
Affects one user or multiple users:
Severity: access blocked | research blocked | incorrect or missing data | client setup help
```

Access blocked means no authorized user in your organization can connect.
Research blocked means the client connects but core read tools fail.

Run the verification prompt first, and include its output if it fails.
