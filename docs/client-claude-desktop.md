# Claude Desktop

Open **Customize → Connectors → Add custom connector** and paste
`https://elevenflo.com/mcp`. Use `elevenflo` for the server label. Claude
Desktop opens ElevenFlo sign-in and consent on the next screen.

Custom connectors are available on every Claude plan. Free accounts can add one.

> [!TIP]
> On Team and Enterprise, an owner adds the connector once under
> **Admin Settings → Connectors**. Members then connect it from
> **Customize → Connectors**.
